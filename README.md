# Leaf Segmentation with YOLOv8

This project uses Ultralytics YOLOv8 to train a model for leaf segmentation. It includes scripts for dataset preparation, model training, and prediction.

## Prerequisites

*   Python 3.8 or later
*   PyTorch (GPU version with CUDA recommended, or CPU only)
*   Ultralytics YOLO
*   OpenCV (`opencv-python`)
*   scikit-learn
*   Other common Python packages (e.g., `numpy`, `yaml`)

You can install the necessary Python packages using pip:
```bash
pip install torch torchvision torchaudio
pip install ultralytics opencv-python scikit-learn pyyaml
```
Ensure you have the correct PyTorch version for your CUDA setup if you plan to use a GPU. Visit the [PyTorch website](https://pytorch.org/get-started/locally/) for installation instructions.

## Dataset Preparation

### Input Data Structure

Your raw image and mask data should be organized as follows:

```
DATA/
├── IMAGES/
│   ├── image1.jpg
│   ├── image2.png
│   └── ...
└── MASKS/
    ├── image1.jpg  # Corresponding mask for image1.jpg
    ├── image2.png  # Corresponding mask for image2.png
    └── ...
```

**Important Mask Naming Convention:**

The mask images in the `DATA/MASKS/` directory **must** correspond to the original images in `DATA/IMAGES/`. The naming convention for masks is critical for the `convert_dataset.py` script to correctly pair images and masks.

While the script is designed to handle various extensions, for the segmentation masks, the script `convert_dataset.py` (as per the original notebook) expects mask filenames to be identical to their corresponding image filenames. For example, if you have `DATA/IMAGES/plant_001.jpg`, its mask should be `DATA/MASKS/plant_001.jpg`.

The script `convert_dataset.py` will then process these masks and save them in the YOLO format with the naming convention `segmented_{original_basename_without_extension}.jpg` in the output directory structure.

### Using `convert_dataset.py`

This script converts your raw images and masks into the YOLOv8 segmentation format. It creates label files (`.txt`) and organizes the dataset into `train`, `val`, and `test` splits.

**Command-line example:**

```bash
python convert_dataset.py \
    --images_dir DATA/IMAGES \
    --masks_dir DATA/MASKS \
    --output_dir Leaf_segmentation_dataset \
    --test_size 0.2 \
    --val_size 0.1 \
    --random_state 42
```

**Arguments:**

*   `--images_dir`: Path to the directory containing the original images.
*   `--masks_dir`: Path to the directory containing the mask images.
*   `--output_dir`: Path where the YOLO-formatted dataset will be saved.
*   `--test_size`: Proportion of the dataset to include in the test split (e.g., 0.2 for 20%).
*   `--val_size`: Proportion of the dataset to include in the validation split (e.g., 0.1 for 10%).
*   `--random_state`: Seed for random number generation to ensure reproducible splits.

### Expected Output Structure (YOLO Format)

After running `convert_dataset.py`, the output directory (`Leaf_segmentation_dataset` in the example above) will have the following structure:

```
Leaf_segmentation_dataset/
├── images/
│   ├── train/
│   │   ├── image1.jpg
│   │   └── ...
│   ├── val/
│   │   ├── imageX.jpg
│   │   └── ...
│   └── test/
│       ├── imageY.jpg
│       └── ...
├── labels/
│   ├── train/
│   │   ├── image1.txt  # YOLO format label for image1.jpg
│   │   └── ...
│   ├── val/
│   │   ├── imageX.txt
│   │   └── ...
│   └── test/
│       ├── imageY.txt
│       └── ...
└── dataset.yaml  # Dataset configuration file for YOLO training
```

The `dataset.yaml` file will contain paths to the train and validation sets, and class information.

## Model Training

The `train_leaf_segmentation.py` script is used to train the YOLOv8 segmentation model.

**Command-line examples:**

*   **Using GPU (recommended):**

    ```bash
    python train_leaf_segmentation.py \
        --data_yaml Leaf_segmentation_dataset/dataset.yaml \
        --epochs 100 \
        --batch_size 8 \
        --img_size 640 \
        --model_name yolov8n-seg.pt \
        --project_name Leaf_Segmentation_Training \
        --run_name run1_100_epochs \
        --device 0
    ```

*   **Using CPU:**

    ```bash
    python train_leaf_segmentation.py \
        --data_yaml Leaf_segmentation_dataset/dataset.yaml \
        --epochs 50 \
        --batch_size 4 \
        --img_size 640 \
        --model_name yolov8n-seg.pt \
        --project_name Leaf_Segmentation_Training \
        --run_name run_cpu_50_epochs \
        --device cpu
    ```

**Key Command-Line Arguments:**

*   `--data_yaml`: Path to the `dataset.yaml` file generated by `convert_dataset.py`.
*   `--epochs`: Number of training epochs.
*   `--batch_size`: Batch size for training. Adjust based on your GPU memory (or CPU capabilities).
*   `--img_size`: Image size (width and height) for training. YOLOv8 will resize images to this dimension.
*   `--model_name`: Pre-trained YOLOv8 model to use as a base (e.g., `yolov8n-seg.pt`, `yolov8s-seg.pt`).
*   `--project_name`: Name of the project directory where training runs will be saved.
*   `--run_name`: Name for the specific training run.
*   `--device`: Device to use for training. `0` for the first GPU, `cpu` for CPU.

### Monitoring Training and Results

Training progress (metrics, logs) will be saved under the directory specified by `--project_name` and `--run_name`. For example:

```
Leaf_Segmentation_Training/
└── run1_100_epochs/
    ├── weights/
    │   ├── best.pt  # Best model weights based on validation performance
    │   └── last.pt  # Model weights from the last epoch
    ├── events.out.tfevents... # TensorBoard logs
    ├── results.csv
    └── ... (other logs and plots)
```

The best performing model is saved as `best.pt` in the `weights` subdirectory.

## Prediction (Inference)

Once the model is trained, you can use it for prediction on new images.

### Command-Line Prediction with `yolo`

You can use the YOLO CLI for quick predictions:

```bash
yolo predict model=Leaf_Segmentation_Training/run1_100_epochs/weights/best.pt source=/path/to/your/new_image.jpg save=True
```

This will save the prediction results (image with segmented masks) in a `runs/segment/predict` directory by default.

## Incorporating Other Datasets (Future Consideration)

While this project initially focuses on the user's custom dataset, several public datasets for leaf segmentation were explored. Future work could involve adapting the preprocessing and training pipeline for these datasets. Some examples include:

*   **Multi-Spectral Leaf Segmentation (INRAE):** This dataset provides multi-spectral images, which would require adjustments in data loading and potentially model architecture if all spectral bands are to be used.
*   **PS-Plant Dataset (PhenoSeeder Plant Dataset):** This dataset contains RGB images of plants in trays, which might be more directly compatible but could have different annotation formats or image characteristics (e.g., multiple plants per image, varying backgrounds).

The primary challenge with these datasets is often the diversity in data types (RGB, multi-spectral, depth) and annotation formats, requiring specific preprocessing steps for each.
